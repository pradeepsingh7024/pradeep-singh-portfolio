## 💡 CUSTOMIZATION (If Needed)

### Change Accent Color
Edit `:root` in style.css:
```css
--accent: #22D3EE;     /* Change this */
--highlight: #6366F1;  /* And this */
```

### Adjust Spacing
Edit spacing tokens:
```css
--rd: 8px;    /* Button radius */
--rd2: 12px;  /* Card radius */
--rd3: 20px;  /* Large radius */
```

### Speed Up Animations
Edit keyframe durations:
```css
animation: float 6s ease-in-out infinite;  /* Change 6s */
```
